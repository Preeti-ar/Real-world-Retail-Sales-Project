# Real-World Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using Python to understand revenue, profit, product performance, and regional performance.

## Objectives
- Calculate total revenue and profit.
- Compare sales across product categories.
- Identify top-performing products.
- Compare profit across regions.
- Visualize daily sales trends.

## Tools
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains product, category, region, date, units sold, unit price, and unit cost.

## Analysis
Revenue = Units Sold × Unit Price

Profit = Units Sold × (Unit Price − Unit Cost)

## Visualizations
- Revenue by Category
- Profit by Region
- Daily Sales Revenue

## How to Run
Install dependencies:

pip install -r requirements.txt

Run the analysis:

python analysis.py

The script saves analyzed data and charts in the outputs folder.

## Conclusion
This project demonstrates data cleaning, sales analysis, profit calculation, and visualization using Python.

## Limitation
The included dataset is sample data created for educational purposes, not actual business records.
